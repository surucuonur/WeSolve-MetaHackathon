# Versions of the muse-round skill

*Written by Claude Code (Claude Opus 5.5), directed by surucuonur. [Who made what](../../../PROVENANCE.md).*

The skill is this folder: `SKILL.md` for the lead, the role cards and `tracking.md`, versioned together. Claude raises the version with every change, and commits it on main before the round that first uses it. Each round records the version it ran in its READMEs and its `summary.md` (round 1: `muse-spark/summary.md`; round N: `muse-spark/round-<N>/summary.md`). Newest first:
